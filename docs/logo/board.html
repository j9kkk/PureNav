PureNav · 标识方案对比

6 个方向，同一套约束：32 单格 / 描边 ≥ 2.4 / 20px 可读 / 深浅色一双

01 航线收束 功能
30px
20px 真实

自网格左下起笔转折向上，收束至指向目的地的导航箭头。隐喻从海量书签入口走入，经纯净筛选直达目标站点。

输在 转折与箭头为不对称构图，偏向单侧可能损失居中仪式感。

02 极简罗盘 功能
30px
20px 真实

两段对称折线沿东北航向对峙，以最简笔画构建指北磁针。中心留白切断闭合，赋予静态罗盘极速与聚焦的导航动势。

输在 对角斜向构图较抽象，缺乏刻度环可能被误认为抽象几何。

03 路径 P 字根
30px
20px 真实

竖笔化为直达航线，顶端 45° 锐角带出 go 动势。圆头碗口开放透气，20px 下仍一眼识别为字母 P。

输在 箭头偏向探索动线，弱化了纯工具的书签感。

04 开放 N 字根
30px
20px 真实

双柱锚定网格卡片，斜笔开放 3.4 单位透光断口。取 Nav 导航之意，比 P 更直指多列网关的连接语义。

输在 首字母非 P，对强调品牌全称 Pure 略显间接。

05 网格网关 抽象
30px
20px 真实

取意主栏与双卡片网格，纯几何抽象重构导航界面。三块厚实矩形告别碎点，20px下中缝呼吸自如清晰。

输在 布局偏写实卡片秩序，未加动效前缺乏动态张力。

06 堆叠书签 抽象
30px
20px 真实

前置经典燕尾书签卡，右上错位浮出数据厚度层。双层均超2.4单位厚度，小尺寸下层级分明绝不黏连。

输在 层叠隐喻依赖辨识度，缩至极小时易被看作折角卡。

07 现网基线 基线
30px
20px 真实

一条路线收成字母 P：竖笔是路径，碗口在回到竖笔前停住（开口 1.6 单位），表示“这条路还没走完”。

输在 对照基准；未融入导航动势，20px 下开口极细微，易被误判为常规闭合 P。
