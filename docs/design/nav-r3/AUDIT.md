## 结构性问题（按严重度）

### P0-1 中段真空：布局算法导致，不是视觉微调能救的

`styles.css:522` `.topbar-actions { flex: 1 1 0 }` 让右侧动作组吃掉全部剩余宽度；
`styles.css:423` `.search { flex: 0 1 420px }` 只允许搜索缩小、永不放宽。
两者叠加 ⇒ 任何 ≥1100px 的屏上，搜索框固定 420 宽、其余全变成空档。
修法方向：搜索必须是唯一可增长的弹性项（`flex: 1`），动作组 `flex: none`。

### P0-2 玻璃上叠玻璃：违反 DESIGN.md 第 3 条

`.icon-btn` 从 `styles.css:486` 继承了 `border: 1px var(--border)` + `background: rgba(255,255,255,.82)` + `backdrop-filter: var(--glass-blur)`；
`glass.css:284` 只把它改成 34×34/radius 12，没有撤掉这三样。
结果：玻璃栏里躺了 3 块 82% 不透明的白瓷砖，各自再模糊一次背景。
时钟胶囊同理（`styles.css:326`：`--bg-elevated` + `blur(12px)` + 边框）。
DESIGN.md「topbar-glass：内部控件只用填充和活力色——禁止在玻璃上再叠玻璃」被直接违反。
这是"三块瓷砖浮在玻璃上"读感的机制来源，不是阴影太重。

### P0-3 时钟侵占品牌区：层级错误 + 抢眼

时钟（`styles.css:326`）是 `.brand` 的第三个子元素，距标题只 4px，且它自成胶囊、有边框、有背景。
功能上它是最弱一级信息（`caption` / `--text-dim`），视觉上却是品牌组里唯一带容器的元素，
比标题更"像个按钮"。同时它是页面唯一按分钟重绘的元素，把注意力从"扫站点"上拽走。
修法方向：移出品牌组、去掉容器、降到纯文字（或干脆收进动作组最右）。

### P1-1 圆角与高度没有唯一节奏

容器 20、内部控件却同时是 8 / 12 / 9999。按 DESIGN.md「同心圆角：内元素 = 外半径 − 内边距」，
栏内 8px 内边距 ⇒ 内部控件应统一取 12，且六档之外的 9999 不应出现在栏内。
高度同理：DESIGN.md 控件 36 高，实现里是 40/34/30/28 四套。

### P1-2 快捷键提示重复

placeholder 写"搜索站点或敲 /"，右侧又挂一个 `/` 键帽（`NavPage.tsx:712,715`）。
同一条信息说了两遍，占掉搜索框内 40px 右侧内边距。二者留一个。

### P1-3 图标语义与图标形状不符

第一个按钮是**视图切换**（grid ↔ list），画的却是汉堡三横线——汉堡在通用认知里是"菜单"。
管理后台用滑块图标，与"设置/偏好"混淆。三个按钮都没有可见标签，只能靠 hover 的 title。

### P2-1 两条 chrome 形状不统一

顶栏 20 圆角矩形、标签条 9999 胶囊，垂直间距靠 `margin-top: -14px` + `margin-bottom: 26px` 手调。
两块 chrome 之间没有对齐关系（标签条右缘悬空），页面读作"一条工具栏 + 一颗散落的药丸"。

### P2-2 空态/窄屏缺失

900px 断点只是 `display: none` 掉时钟（`styles.css:3521`），
640px 用 grid 把搜索换行到第二行（`styles.css:3527`）——此时玻璃栏内边距 14 与换行后的搜索左缘不对齐。

## 重构必须守住的不变量

1. 玻璃只在功能层；栏内控件禁叠玻璃（只用 `--lg-inset` / `--hover-fill` 级填充）。
2. 圆角只走六档；栏内控件 = `--lg-r`(20) − `--lg-pad`(8) = 12。
3. 控件高度收敛到一档（36）或显式两档，不再出现 28/34/40 混排。
4. 无彩：除品牌图标与焦点环，界面不出现第二处彩色。
5. 动效只走 `--dur-fast/base/slow` + `--ease-*`。
6. 入口不冗余：同一功能只有一个入口，低频操作进溢出菜单。
7. 4px 基线间距（4/8/12/16/24/32），2px 只做控件内部紧凑步长。
