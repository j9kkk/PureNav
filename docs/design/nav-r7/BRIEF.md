# PureNav r7 —— 全能自托管收藏夹管理器（Bookmark Manager）设计任务书（BRIEF）

## 1. 为什么从「启动页门户」转向「全能收藏夹管理器（A 方向）」

前两轮（r5 / r6）围绕「24 个固定站点的单页全平铺门户（Startpage）」做了 6 版不同皮肤与容器形态，但当回归 PureNav 的原始使命——**「帮助用户更好地管理网页收藏夹」**——时，单页全量平铺暴露出四大根本断层：
1. **规模断层（Scale）**：一旦导入浏览器真实收藏夹（成百上千条书签、几十个多级文件夹），单页纵向平铺会变成滚不到底的灾难；而单条目子文件夹（如 `Apple 研发`）放在平铺画布里又会产生大面积空洞。
2. **前后台割裂（Split Brain）**：日常改个标题、挪个文件夹、删条失效书签，必须离开主界面去 `/admin` 后台翻表格。真正的书签管理器（如 Chrome Bookmark Manager、Raindrop.io、Arc、Linkding）全部是**「浏览与原地管理合一」**。
3. **收录摩擦大（Capture Friction）**：新增书签要手填 4 个字段，没有「粘贴 URL 自动抓取标题/描述/图标 + 重复网址实时预警」，也没有「浏览器书签栏一键收录（Bookmarklet）」入口。
4. **缺少全生命周期治理（Lifecycle & Doctor）**：没有点击热度统计（`visit_count` / `last_visited_at`），没有「待整理收件箱（Inbox）」，没有针对历史烂账的「书签体检（重复 URL 合并 + 404 死链巡检 + 301 重定向更新）」。

### 关键空间与交互设计规则：
1. **彻底消灭「单条目子分组（Apple 研发）占满整行白洞」**：
   - 当用户在左侧点击某个含子目录的文件夹（如 `开发与基础设施`），右侧工作区顶部先渲染一行紧凑的**「子文件夹导航卡（Subfolder Pills / Cards）」**：`[📁 文档与规范 · 3 ›]`、`[📁 Apple 研发 · 1 ›]`。
   - 点击子文件夹卡可直接钻取进入该子目录（顶部面包屑变为 `全部书签 / 开发与基础设施 / Apple 研发`）；同时右侧下方按清晰分组或平铺展示书签条目。无论子文件夹里有 1 条还是 50 条，都绝不会撑出右半屏白洞！
2. **顶部「常用置顶 Dock」**：
   - 在 `全部书签` 视图下，顶部展示 `常用置顶` 横向紧凑快捷槽（6 个高频/置顶站点：如 `GitHub`、`Synology NAS [内网]`、`Figma`、`MDN Web Docs`、`Vercel`、`Hacker News`），单卡仅 1 行高（`36px`），让每天点 10 次的高频站点 0 滚动直达，又不侵占主列表空间。
3. **双列高密度书签矩阵（默认） + 单列紧凑清单视图（可切换）**：
   - 默认主列表采用 **2 列严整对齐的书签行卡（Row Card）**（每张卡高约 `60px`）：
     - 第一行：左侧 `28px` 几何双字母微章 + **站点标题（`14px` 粗）** + **等宽域名/IP（`12px`）** +（若有内网地址）`[内网/外网]` 切换胶囊；右侧显示 **标签胶囊** + **访问热度（如 `142次`）** + 悬停显露的 `[···]` 菜单触发器。
     - 第二行（左对齐标题）：**完整无截断的站点说明（`12px`）** + 所属文件夹路径徽标（在“全部书签”视图下显示如 `开发 / 文档与规范`）。
   - 点击顶栏视图切换按钮，可切为 **单列极简表格行视图（Compact Table View）**，一屏容纳 16+ 条。
4. **低频操作全部收进「右键菜单（Context Menu）」**：
   - 严禁在书签卡片表面平铺“编辑/删除/移动/置顶”四个图标按钮（拒绝入口冗余）。
   - 在任意书签上 **右键点击**（或点击卡片右侧 `···` 按钮，或通过 `?modal=context` URL 参数直达演示），在对应书签旁弹出精密对齐的**原地管理右键菜单**：
     - `在新标签页打开` (`Enter`)
     - `切换为内网/外网地址`（仅含 `lanUrl` 站点可用）
     - `设为常用置顶 / 取消置顶`
     - `移动到文件夹 ▸`（展示二级文件夹快捷选择或直接移动）
     - `编辑书签信息…`
     - `复制网址`
     - `移入待整理收件箱`
     - `删除书签`（危险红字）
5. **1 秒快速收录弹窗（Quick Capture Modal，`?modal=capture` 或点左侧 `+ 快速收录` 按钮）**：
   - 展示核心卖点：**粘贴 URL 自动抓取网页元信息 + 重复网址预警 + 浏览器 Bookmarklet 小书签**。
   - 弹窗顶部：URL 输入框（带 `[自动抓取元信息]` 状态标签：已就绪 / 解析成功），当输入或演示预设 URL（如 `https://vite.dev` 或新网址 `https://linear.app/docs`）时：
     - 若检测到库内已有重复网址，显示醒目的琥珀色防重横幅：`检测到已存在相同域名书签「Vite」（位于：开发与基础设施 / 文档与规范），可一键合并或继续保存`。
     - 自动回填抓取到的 `网页标题`、`Meta 描述`、`推荐双字母微章`、`智能推荐文件夹（或存入「待整理收件箱」）`、`标签选择`。
   - 弹窗底部附带一行精致的**「浏览器一键收录小书签（Bookmarklet）」**提示条：`将 [➕ 存入 PureNav] 拖到浏览器书签栏，浏览任意网页时点一下即可 1 秒收录`。
6. **书签体检中心视图（Bookmark Doctor，`?view=doctor` 或点击左侧 `🩺 书签体检 3`）**：
   - 当切换到 `书签体检` 视图时，右侧主工作区切换为专门的**收藏夹健康治理面板**：
     - 顶部体检摘要卡：`全库 24 条书签 · 健康 21 条 · 发现 3 项待清理问题` + `[重新扫描全库]` 按钮。
     - 问题列表（真实基于 24 条数据集构造的 3 类典型治理场景）：
       1. **【重复收藏】** `Vite` (`https://vite.dev`) —— 检测到在 `开发与基础设施 / 文档与规范` 与 `待整理收件箱` 中存在归一化后相同的网址 → 操作按钮：`[合并保留一条]` `[忽略]`
       2. **【301 域名重定向】** `React Docs` (原收藏 `https://reactjs.org` → 自动检测已永久重定向至 `https://react.dev`) → 操作按钮：`[一键更新为新网址]` `[忽略]`
       3. **【连接超时 / 离线预警】** `Immich 家庭相册` (内网 `http://192.168.1.10:2283` 探测超时，已自动回退外网 `https://photo.tdcode.tech`) → 操作按钮：`[切换默认外网]` `[复测连接]`

## 3. URL 参数契约（供自动化截图与主线程逐项验收）

页面初始化时必须解析 `window.location.search`，支持以下全部状态直达：
- `?theme=dark`（默认） / `?theme=light`：切换暗色 / 浅色主题。
- `?view=all`（默认）：展示「全部书签」视图（含顶部 `常用置顶 Dock` + 文件夹分组与子文件夹导航条）。
- `?view=folder&folder=dev`：直达选中左侧 `开发与基础设施` 文件夹（顶部展示面包屑 `全部书签 / 开发与基础设施` + 两个子文件夹入口卡 `文档与规范 (3)` 与 `Apple 研发 (1)` + 直属书签与子目录书签）。
- `?view=inbox`：直达「待整理收件箱（2）」视图。
- `?view=doctor`：直达「书签体检（3）」健康治理视图（展示重复收藏合并、301 重定向更新、内网不可达回退三项体检卡片，点击操作按钮可实时修复并更新计数！）。
- `?modal=capture`：打开「快速收录书签（Quick Capture）」弹窗（展示 URL 自动抓取回填、重复 URL 预警条、Bookmarklet 拖拽入口）。
- `?modal=context`：在第一条书签（如 `GitHub` 或 `Synology NAS`）旁默认展开「右键原地管理菜单」，供截图验收右键菜单的排版与对齐。
- `?q=<关键词>`：搜索过滤（支持匹配标题、域名、内网 IP、说明、标签、所属文件夹名、以及常用拼音缩写如 `nas` / `ss` / `少数派`）；`?q=notfound99` 触发无结果兜底面板（含 `Google / GitHub / Bing / 百度` 站外搜索与 `清空筛选`）。
- `?state=empty`：初始空库状态（含「导入浏览器书签 HTML」与「+ 快速收录第一个网站」引导）。

## 4. 视觉与工程硬性红线（继承并强化）

1. **严禁 Emoji 与外部图片请求**：全页 DOM `innerText` 零 Emoji（文件夹、图钉、收件箱、体检听诊器/脉冲、右键菜单图标一律用 `1.5px` 线性 SVG）；站点图标一律用双字母几何微章（Monogram）。
2. **全局唯一焦点环与边框纪律**：所有组件圆角收敛在 `6px`（小胶囊/按钮）与 `8px`（卡片/弹窗/菜单），严禁 `16px+` 臃肿大圆角；`:focus-visible` 统一为 `2px solid var(--accent)`。
3. **零截断与对比度红线**：
   - 在 `1440×900` 与 `640×900` 下 `scrollWidth <= innerWidth`；
   - 所有可见文字（标题、说明、域名、子文件夹名、按钮、标签）`scrollWidth <= clientWidth`（`truncCount === 0`）；
   - 暗色与浅色主题下所有可见文字对比度 ≥ `4.6:1`（`lowContrastCount === 0`）。
4. **字号与字重收敛**：全页字号去重后 `<= 6` 档（如 `11px, 12px, 13px, 14px, 16px, 20px`），字重仅限 `400, 500, 600`。
